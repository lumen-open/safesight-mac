# Reporting a weakness

SafeSight Mac is designed so that its protections hold with every line of code public. If you find a way to end a lock earlier than its owner's chosen wait, by any route other than the known, published gaps, please report it **privately**:

- use GitHub's "Report a vulnerability" button on this repository (private vulnerability reporting).

Please do not post details in public issues, discussions or pull requests. Public posts that describe a way around the lock are hidden and moved to a private report.

What happens next:
- we confirm we received it;
- a fix ships through the normal release process (every update waits 14 public days; changes to the keeper wait each owner's own wait plus 2 days);
- the write-up is published after the fix has reached owners.

Known gaps that are already public, and need no report: erasing the Mac, recovery mode, unpatched macOS security bugs, and Safe Mode if it is not covered. They are listed in the project's losses list.
